## Latest web edition

[Open the web edition source](web/index.html). **Web edition prepared; Sites deployment pending.** No live Sites URL has been verified yet. Serve the repository locally with `python -m http.server 8000` and open `http://localhost:8000/web/`.

The original research prototype is not a validated veterinary diagnostic service. The browser workbench compares a trailing-mean baseline on invented activity values; it is not the original neural network and its MAE is illustrative.
